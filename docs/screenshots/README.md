# Screenshots

This directory contains visual documentation of the Cargo Ship Monitoring Platform in action.

## Expected Screenshots

| File | Description |
|------|-------------|
| `docker-compose-up.png` | Terminal showing all services starting via Docker Compose |
| `api-response.png` | curl or Swagger UI showing successful event ingestion |
| `dashboard.png` | React landing page with live fleet dashboard |
| `sqlite-events.png` | SQLite browser or CLI showing stored events table |
| `jaeger-trace.png` | Jaeger UI showing a distributed trace from ShipEdge to FleetCloud |

> Screenshots should be captured after running the full stack with `docker-compose up --build`.
